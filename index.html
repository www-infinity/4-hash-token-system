🧱 C13B0 — 4-Hash Token System

Verifiable research tokens with four independent SHA-256 hashes

MIT  ·  Node.js  ·  SHA-256

Core Features

🔐 4-Hash Integrity

Every token seals article, sources, combined package, and metadata with independent SHA-256 hashes. Any modification is detected instantly.

🌀 Spin Research Writer

Turns every spin event into a permanent science research packet — article, sources, equations, ontology, and token, all in one sealed cartridge.

🔬 Science Seed Bank

1,003 ontology terms across 20 scientific domains power the research writer. New terms grow from arXiv queries without touching the starter bank.

🔑 User Auth

bcrypt-hashed passwords and AES-256-GCM encrypted profile files. No plaintext passwords are ever written to disk.

4-Hash Model

HashProtects
HASH1Research article only
HASH2Sources / citations only
HASH3Combined research package (article + sources)
HASH4Token identity metadata
